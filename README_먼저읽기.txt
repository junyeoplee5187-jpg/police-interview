경찰면접 스터디 센터 | 클라우드 배포용 1.0
===========================================
관리자 1명 + 조원 8명. 관리자 PC를 켜둘 필요 없음.
조원은 배포된 HTTPS 주소와 자신의 이메일/비밀번호만 있으면 됩니다.
관리자/조원 모두 Python, Node, 별도 프로그램 설치 불필요.
OpenAI API, GPT 구독 공유, 결제 API, 자동충전 없음.
단, 실제 공개 주소는 아래 최초 설정 후 발급됩니다. 아직 배포되지 않았습니다.

[1] Supabase 무료 프로젝트 (https://supabase.com/dashboard)
- 반드시 Free 조직에서 새 전용 프로젝트 하나를 만드세요. 결제수단/유료 옵션을 등록하지 마세요.
- Authentication > Users > Add user > Create user: 관리자 1명과 조원 8명의 개별 이메일, 강력한 임시 비밀번호를 등록하고 이메일 확인 처리합니다. 각 계정은 실제 이용자 이메일로 만들고 비밀번호는 개인에게만 전달하세요.
- Authentication 설정에서 신규 공개 가입(Allow new users to sign up)을 꺼 주세요. 사용자 추가는 관리자 대시보드에서만.
- SQL Editor > New query에 setup.sql 전체를 붙여넣기. CHANGE_ADMIN_EMAIL@example.com 부분을 관리자 이메일로 바꾼 뒤 Run. 정확히 9명일 때만 실행됩니다. 최초 한 번만 실행하세요. 다른 프로젝트에 섞어 쓰지 마세요.
- Project URL과 publishable key(또는 기존 anon key)를 복사. site/config.js를 메모장으로 열어 두 값을 입력하고 저장. 서비스 역할 키, secret key, DB 비밀번호는 절대 사이트에 넣지 마세요.

[2] 서버 함수 배포 (브라우저만 사용)
- Supabase > Edge Functions > Deploy a new function > Via Editor. 이름을 study-submit 으로 지정.
- index.ts 전체를 edge-function.ts 내용으로 교체 후 Deploy.
- 함수의 Verify JWT / Verify JWT with legacy secret 설정을 OFF로 설정. 함수 자체에서 전달된 사용자 토큰을 Supabase Auth로 확인하고 study_members의 허용 계정을 검사합니다. 이 설정을 끄는 대신 인증 코드가 반드시 포함되어야 합니다.
- 기본 서버 환경 변수 SUPABASE_URL 및 SUPABASE_SERVICE_ROLE_KEY를 사용합니다. 이 키를 웹사이트나 조원과 공유하지 마세요.

[3] 사이트 배포 (https://dash.cloudflare.com)
- 무료 계정 > Workers & Pages > Create application > Pages > Direct Upload(또는 Drag and drop).
- 이름 지정 후 config.js를 수정한 site 폴더를 통째로 드래그. 또는 수정된 site 폴더 안의 5개 파일을 ZIP으로 묶어 올립니다(압축 최상위에 index.html).
- Deploy site. 화면에 생긴 https://...pages.dev 주소를 관리자 및 조원에게 전달.
- 결제수단 등록, 유료 플랜, 별도 도메인 구매는 불필요합니다. 무료 한도 초과 시 사용을 중단하고 유료 업그레이드하지 않습니다.

[4] 실제 배포 후 점검 — 테스트 녹음으로만 시행
1. 관리자와 조원 A, 조원 B가 각각 로그인. 등록하지 않은 계정은 거절되는지 확인.
2. 조원 A가 녹음 안내 동의 후 2개 본질문/2개 꼬리질문 면접, 마이크 허용, 녹음 제출. 자동전사는 선택이며 브라우저에 따라 실패할 수 있음.
3. A 본인 PDF 열림, 음성 접근 불가. B는 A의 PDF 및 녹음 접근 불가. 관리자는 A의 PDF 및 음성 재생/다운로드 가능.
4. 관리자 삭제 또는 조원 삭제 요청 확인. 테스트 자료를 삭제. 저장량이 줄어드는지 확인.
5. 실제 800MB를 채우지 않고도 별도의 테스트 프로젝트 SQL에서 한도를 줄여 자동삭제를 검증할 수 있습니다. 운영 프로젝트의 800000000 값은 변경하지 마세요.
6. 관리자 PC를 종료하고 휴대전화 LTE/5G로 재접속 확인.

[운영 정책]
- 질문 28세트(본질문+미리 작성된 꼬리질문), 유형별 무작위. 실시간 GPT가 아님.
- 자체 평가: 전사 길이와 관련 키워드 기반 점검. 법령 검증, 의미 이해, 진실성, 면접 합격 가능성 판단은 하지 않음. 전사 없는 문항은 미평가. PDF는 이미지 기반이며 텍스트 선택/검색 불가.
- 답변만 녹음. 문제별 3분, 2MiB 제한, 면접별 4~8문항. PDF 최대 4MiB. 제출 시에만 녹음 및 PDF를 업로드.
- 녹음은 관리자만, PDF는 본인 및 관리자만 다운로드. 별도 실시간 청취 없음. 처음부터 녹음 및 관리자 접근 동의, 중단/취소 및 삭제 요청 기능.
- 파일 최대 예약량 800,000,000 bytes (800MB decimal). 1GB decimal 기준 200MB 남기는 정책. 전용 프로젝트에서만 보장하도록 설계. 제출 전에 SQL에서 공간을 예약하며, 저장 실패나 삭제 실패 시 예약을 유지해 초과 업로드를 차단합니다. 오래된 완료 녹음부터 삭제하고, 모두 삭제되어도 부족한 경우 오래된 완료 PDF를 삭제. 사용자 화면의 용량은 실제+예약 기준.
- 서버 장애 시 제출 미완료가 남을 수 있음. 관리자는 10분 이후 해당 미완료 기록 삭제 가능. 삭제 중 상태가 고착되면 신규 업로드가 안전하게 거절될 수 있음. 이 경우 Supabase Storage에서 해당 보고서의 실제 파일을 모두 제거했는지 확인 후 DB 상태를 정리해야 하며, 확인 없이 예약을 지우면 안 됩니다. 정상 운영 때 Storage/DB를 직접 수정하지 마세요.
- Supabase 무료 정책: 저장 공간 이외에도 전송량, DB, 서비스 호출 제한 및 유휴 프로젝트 일시정지가 있을 수 있음. 무료 플랜을 유지해야 과금 없이 사용할 수 있습니다. 24시간 무중단 보장은 아님.
- 브라우저 한국어 음성합성이 없으면 화면 질문으로 진행. 자동 전사 선택 시 브라우저 제공업체 음성 서비스로 전송될 수 있어 별도 체크박스 제공. Chrome/Edge 권장, Safari 및 실제 휴대전화 미검증.

[검증 결과]
- JavaScript 및 Edge TypeScript 구문 검사 통과.
- Chromium 내 가상 오디오 스트림 및 모의 클라우드 API: 동의 확인, 4문항, 녹음 파일 생성, 실제 multipart 제출 데이터, PDF 렌더링, 관리자/조원 UI 구분, 녹음 가져오기 통과.
- Node에서 Edge Function 실행 + 모의 DB/스토리지: 비인가 토큰, 비회원, 동의 누락, 조원 용량 접근 거부, 저장, 녹음 우선 삭제, PDF 후순위 삭제, 삭제 실패 시 업로드 차단 통과.
- 실제 Supabase SQL/RLS, 동시 제출, 클라우드 스토리지, 실제 마이크·한국어 음성, Windows/모바일, 외부 배포 링크는 미검증. 최초 배포 후 [4] 점검이 필요합니다. 테스트 코드는 tests 폴더에 포함하며 사용자가 실행할 필요는 없습니다.
